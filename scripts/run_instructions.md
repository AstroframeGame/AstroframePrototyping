# AstroFrame

Thank you for Downloading! you can get the latest version from itch.io.
[itch.io](https://sentientdragon5gamedev.itch.io/astroframeprototype)

To run Astroframe, unzip then double click the executable.

## Multiplayer
Steam multiplayer is supported!!
Please claim a steam key and use it to add AstroFrame Playtest to your library.
[Steam Keys for Teaching Team](https://docs.google.com/spreadsheets/d/1nDk2Sjj2V8alW8BUAPW4jJh4TUfNztu2ckqrv_liGNk/edit?gid=501821190#gid=501821190)

Multiplayer can be triggered from the steam overlay (may not work) or through host's Invite button on pause screen.

To run in single player, launch the executable normally.

To run in multiplayer locally, launch multiple windows from multiple terminals with the `--local` run argument.

Then start the game on one instance (press Play) then press Join Local on the client instance.

## Controls
- WASD : Movement
- Space Ctrl : Up and Down in space
- Space : Jump
- Shift : Sprint
- Left Click : Shoot
- Right Click : Aim, Strafe
- ~ : to quit the game
- ESC : Pause
- TAB : (Debug) unfocus mouse
