# AstroFrame

Thank you for Downloading! you can get the latest version from itch.io.
[itch.io](https://sentientdragon5gamedev.itch.io/astroframeprototype)

To run Astroframe, unzip then double click the executable.

## Play instructions
Press Start. Then select a level (1 option so far). Build the ship for the level, or click a preset. `a_test` is an ok ship to click.
Then click Continue to Warp. Now in the level you can fly around with WASD.

Known issues with gameplay.
- Collisions are not working. (framework in, build not currently working)
- gun doesnt work right here. works in a separate branch
- currently the objective system doesnt work. will be updated shortly.

## Multiplayer
Multiplayer is no longer supported.

## Controls
- WS: move forward/backward
- AD: turn ship
- Tab (hold): focus ship to set power. Click on the torus to power a room.
- Esc: Pause
